## ⚡ Getting Started

Clone the repository:

```bash
git clone https://github.com/sandeshmangeshjadhav002/SJPortfolio.git
```

Navigate to the project folder:

```bash
cd SJPortfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
